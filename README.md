# Star Trek: Birth of the Federation remake

This private repository contains the Unreal Engine project, standalone C++ simulation, tests, research notes, and asset source needed for the local Windows development workflow.

The preserved playable beta is documented in [the milestone record](planning/milestones/BOTF-20260928-PLAYABLE-BETA.md). Its packaged Windows build and local saves are intentionally kept out of Git. The current source can be ahead of that preserved build; read [the beta review status](game/REVIEW-BETA.md) before treating the source as release-ready.

Unreal Engine builds and interactive visual checks require the project's Windows/Unreal setup. The standalone simulation and source review can be worked on separately. Start with [the game guide](game/README.md) and [the beta acceptance criteria](planning/BETA-ACCEPTANCE.md).

Unreal assets use Git LFS. Community asset credits and author terms are recorded in [game/ASSET-CREDITS.md](game/ASSET-CREDITS.md); retain those notices when using or packaging the included art.
