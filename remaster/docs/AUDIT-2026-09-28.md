# BOTF remake — project audit, 28 September 2026

Scope: the full repository at commit `77eebd6` (the preserved playable-beta import). Four review
passes were made: simulation core, gameplay modules, Unreal client, and tooling/docs/hygiene. The
native suites were also built and run on Linux (GCC 13 and Clang), under ASan/UBSan, and compiled
to WebAssembly.

## Where the project stands

| Layer | Size | Assessment |
|---|---|---|
| Simulation core (`BotfSim/`) | ~11.5k lines C++20 | Strongest asset. It is deterministic, has no engine dependencies, and all turn work runs on copies. Save/load uses checksums. It is portable: GCC, Clang, MSVC and Emscripten all produce identical hashes. |
| Gameplay modules (tactical, diplomacy, intel) | ~5.3k lines header-only | These are feature-rich but only partly integrated. They contain several bugs that break the game (below). |
| Unreal client (`BOTFRemake/`) | ~8.5k lines Slate | Functional, but nearly everything lives in one 4,500-line widget. Many workflows exist: galaxy pan/zoom/double-click/context menu, system management, research, diplomacy, intel and tactical. Visual polish and art are interim. |
| Tests | ~6.3k lines, 151 scenarios | Wide coverage, but on a clean clone the run stopped early. Tests needed save files from the development PC, so 23+ scenarios never ran. Several "determinism" tests only compare two runs within one process. |
| Tooling/docs | Python asset pipeline, PS1 scripts, ~1.2k lines of planning/research | The research is thorough. Status docs are append-only logs that contradict one another. Much of the evidence cited is in files that are not in the repository. |

Measured, before fixes:
- Tactical 12/12, Intelligence 14/14 and Diplomacy 14/14 passed.
- Simulation passed 104/104 and Session 6/6 only once the fixture-dependent scenarios were skipped.
- Sanitizers were clean.
- A 200-turn five-empire reference soak ran at about 1 ms per turn.

Victory is basic: conquest, or 60% of systems. There are no monsters or Borg, no trade goods, no galaxy shapes and no multiplayer.

## Game-breaking defects found (all confirmed with probes)

1. The queue governor sets farm workers without releasing others, so the turn and the save load both throw ("Workforce exceeds population"). Reachable at turn 4 of seed 1999.
2. Capturing a minor-member colony throws "Minor ownership mismatch", because `minors` is not merged back after invasions. The AI triggers this on its own.
3. Research theft breaks the research ledger. Supreme-era soaks crash with no player input.
4. After turn 25, AI empires 2 and 4 re-declare war every turn, so peace with them is impossible.
5. Diplomacy locks permanently after 128 proposals, because resolved proposals are never pruned.
6. Auto-resolved player battles can leave `resume()` throwing forever. AI-chosen maneuvers aren't stored, so the replay diverges.
7. Mid-battle save/load diverges, because standing orders aren't serialized.
8. Ram is free, cloaked ships can fire, and retreat is a guaranteed damage-free escape.
9. Intel state for rivals outside the budget is lost on reload. Floating-point outcome math misrounds (100×29% gives 28).
10. Loading a save re-runs governors, so loading mutates state. Proposal text containing a newline makes the save unloadable.
11. Headless `advance()` and the game resolve battles with two different combat models.

## Structural issues

- The UI has one god-widget. It copies simulation formulas (income and trade), recomputes routes and supply per frame, and runs whole turns synchronously on the game thread.
- In Unreal, focused buttons swallow keyboard shortcuts, and hotkeys fire while typing in text fields. Quit calls `RequestExit` and kills the PIE editor. The UBT floating-point mode may differ from the standalone build.
- Two diplomacy systems and two intel systems (legacy and modern) run side by side and write to each other's state.
- Save versioning has five untagged variants of schema 11, reconstructed by string erasure.
- The Python combat-asset tests fail on a clean clone because git-lfs was not pulled: they hash pointer files. `.ms3d`/`.bmp` binaries are committed outside LFS.
- There was no CI, no CMake and no license. Windows user paths are hard-coded, and PowerShell 7 is required but not stated.
- IP: `ReferenceCatalogue.h` embeds verbatim original game text, despite `.gitignore`'s "never commit" note for extracted data. That is acceptable for a private fan project but must be replaced before any public release.

## Recommendation

Keep the architecture: a pure deterministic core plus thin clients is the right shape. The next steps are to stabilize (fix the defects above behind soak tests), unify combat, and then modernize the gameplay. The work also needs a client that can be played and verified without a Windows/Unreal machine in the loop. See [REMASTER-ROADMAP.md](REMASTER-ROADMAP.md).
